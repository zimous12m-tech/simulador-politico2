# 🏛️ Teoria das Sociedades — Simulador de Políticas Públicas

> **"E se pudesses governar Portugal durante 50 anos? Que decisões tomarias? E quais seriam as consequências reais?"**

O **Teoria das Sociedades** é um simulador educativo e interativo que modela a evolução de uma sociedade ao longo do tempo. Testa políticas públicas, enfrenta crises, e descobre os *trade-offs* escondidos por trás de cada decisão. Sem instalações, sem registos, direto no teu browser.

👉 **[CLIQUE AQUI PARA JOGAR AO SIMULADOR](https://zimous12m-tech.github.io/simulador-politico2/)**

---

## 🎯 Porquê experimentar?

- **É viciante:** Começas com um país estável e, ao fim de 10 minutos, estás a lidar com uma recessão, uma greve geral e uma crise climática.
- **É educativo:** Percebes na prática porque é que é tão difícil equilibrar o orçamento, a economia e a justiça social.
- **É honesto:** O simulador não tem viés político. A mesma ferramenta serve para testar ideias de esquerda, direita ou centro.
- **É português:** Desenvolvido de raiz, com dados reais de Portugal (e de outros 217 países).

---

## 🧠 O que podes simular?

O motor é composto por **13 sistemas interligados** que reagem às tuas decisões:

| Sistema | O que modela |
| :--- | :--- |
| **Demografia** | População, fertilidade, migração, envelhecimento. |
| **Educação** | Anos de escolaridade, qualificação, fuga de cérebros. |
| **Trabalho** | Emprego, setores, automação. |
| **Economia** | PIB, produtividade, salários, desemprego. |
| **Setor Externo** | Exportações, importações, balança comercial. |
| **Política Monetária** | Inflação, taxas de juro, crédito. |
| **Clima e Energia** | Emissões, renováveis, dependência energética. |
| **Estado** | Receita fiscal, despesa pública. |
| **Finanças Públicas** | Dívida, défice, austeridade, *default*. |
| **Habitação** | Preços, rendas, construção, taxa de esforço. |
| **Sociedade** | Coesão social, desigualdade (Gini), confiança. |
| **Política** | Eleições, partidos, aprovação pública. |
| **Crises** | Recessões, choques externos, desastres. |

## 🎮 Como funciona?

1. **Escolhe um país:** 217 países disponíveis com dados reais, ou cria o teu próprio cenário.
2. **Define as políticas:** Ajusta o investimento em educação, saúde, habitação, transição energética, impostos sobre o carbono, e muito mais.
3. **Avança no tempo:** Simula 30, 40 ou 50 anos e vê o impacto das tuas escolhas.
4. **Analisa os resultados:** Gráficos interativos mostram a evolução da economia, da sociedade e das finanças públicas.
5. **Sobrevive às crises:** Ativa o modo "robustez" para testar a resiliência do teu país a choques aleatórios.

## ⚙️ Tecnologia e Filosofia

- **JavaScript puro (ES6)** — Sem frameworks, sem dependências externas (apenas Chart.js para gráficos).
- **Funciona offline** — Podes instalá-lo como PWA e usá-lo sem internet.
- **Código aberto e transparente** — Todo o código está disponível para consulta e modificação.
- **Sem viés político** — O objetivo é educar, não doutrinar. Cada política tem custos e benefícios; o simulador mostra-os.
